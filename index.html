Personal rclone sync

A private desktop workflow for keeping the account owner's files in sync between personal computers and Google Drive.

What this app does

This application uses rclone, an open-source command-line program, and Google's Drive API to synchronize files. It is intended for the owner's personal use. It is not a public file-sharing service or an official Google product.

Why it asks for Google Drive access

Bidirectional synchronization requires permission to list, read, create, update, and delete files in the authorized Google Drive account. The desktop sync configuration determines which folders are synchronized.

How authorization works

Google authorization is completed directly with Google for the locally installed rclone program. This information site has no sign-in form and does not receive OAuth tokens or Drive files.
